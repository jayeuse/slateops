## 1. What you get now

1. You get an early build of Slate Operations. It costs nothing.
2. The early build has every feature and no limits on people or data. It checks no license file.
3. Setup and the app may name the edition "Desk". No Desk limits apply in this build ([Updates & licensing shows "No license required · Self-hosted"](../../frontend/src/components/systems/manage/domain/updates-rules.ts)).
4. You install Slate Operations yourself with the [quick start](quick-start.md). Get the setup file from [where to get the setup file].
5. The early build is a pre-release test build. Its setup program is not code-signed, so Windows can show a warning ([quick start](quick-start.md), "Start setup").

## 2. The license

1. Slate Operations is licensed under the Elastic License 2.0, in the `LICENSE` file that comes with the software.
2. You can use Slate Operations free for your own organization.
3. You cannot offer Slate Operations to other people as a hosted or managed service. You cannot go around a license key.
4. The software comes "as is", as the "No Liability" section of the Elastic License 2.0 says.

## 3. Updates

1. Updates are free.
2. The app shows an update prompt only for a published, stable release. Early builds are not published that way, so the app shows no prompt ([administrator guide](administrator-guide.md), chapter 3).
3. Until then, [owner legal name] tells you when a new setup file is ready. Run the new setup file on the server PC to update ([administrator guide](administrator-guide.md), chapter 3).

## 4. Help

Help is free. Write to [support contact]. The [getting help](getting-help.md) page tells you what to send.

## 5. What comes later

1. A later version adds editions. An edition sets which features you can use and how many people can use Slate Operations. A license file unlocks a paid edition.
2. Edition prices and terms are published with that version. This note promises no edition, price or license file.
3. When that version comes, early users get: [what early users get when licensing starts].
4. No edition deletes your data.

## 6. Your data

Your data stays on your server PC and your backup drive. [owner legal name] does not get a copy. The [data and privacy statement](data-and-privacy.md) explains the details.
