# Slate Operations setup and support order

> **Draft: not legal advice.**
>
> This is a short service order for a few known customers. It sells setup and support, not the software. It has no liability cap, no refund clause and no governing-law clause, and it makes small promises on purpose.

- **Provider:** [owner legal name], of [owner address].

This order starts on [start date].

## 2. Services

1. **Setup.** The Provider installs Slate Operations on one Windows 11 PC of the Customer. The Provider creates the first administrator account. The Provider checks that the Customer can sign in from one PC and one phone.
2. **Yearly support.** The Provider answers questions, helps with problems, installs published updates, and helps with backups and restores. The [support policy](support-policy.md) gives the details.

## 3. The software

1. Slate Operations is licensed under the Elastic License 2.0, in the `LICENSE` file that comes with the software. The Elastic License 2.0 costs nothing. This order does not sell it.
2. The software comes "as is", as the "No Liability" section of the Elastic License 2.0 says.
3. Paid license files for editions start with the first licensed version (section 4).

## 4. The current build

1. The Customer gets an early build. It is a pre-release test build, and its setup program is not code-signed.
2. The early build has every feature and no edition limits. It checks no license file. Setup and the app may name the edition "Desk". No Desk limits apply.
3. The app shows no update prompt for early builds. The Provider installs updates by hand as part of support.
4. Editions, edition prices and license files start with the first licensed version. They need a new written order. This order promises no edition, price or license file.

## 5. Fees

1. Setup fee: [setup fee] [currency], paid once, within [payment days] days after setup.
2. Yearly support fee: [yearly support fee] [currency] for each support year, paid within [payment days] days after the start of that year.
3. Fees do not include the Customer's PC, Windows, internet service, email account, backup drive or other hardware.

## 6. Term and end

1. The first support year starts on [start date] and lasts 12 months.
2. Support continues for another year only when both parties agree and the Customer pays the yearly support fee.
3. Either party can end support with [notice days] days' written notice.
4. When support ends, the Customer keeps the software, the Elastic License 2.0 and all data. The software keeps working without support.

## 7. What support does not cover

1. Hardware faults, Windows faults, and problems with the Customer's network, internet service or email provider.
2. Data loss when the backup drive was not connected, or when nobody acted on a failed-backup warning.
3. Changes that the Customer or another person made to the software, its files or its Linux part.
4. Other PCs or other installations than the one that the Provider set up.
5. Visits on site beyond [visits per year] each support year.
6. New features, custom development and data import from other systems, unless both parties agree in writing.

## 8. The Customer's data

1. The Customer's data stays on the Customer's PC and backup drive. The [data and privacy statement](data-and-privacy.md) explains how.
2. The Provider does not copy the Customer's data.
3. The Provider opens a remote session only when the Customer asks for it. The Customer watches the session and can end it at any time.
4. Before a change on the server PC, the Provider makes sure that a recent backup exists.

## 9. Changes to this order

A change is valid only in writing, agreed by both parties. Notices go to the addresses in section 1 or to [support contact].
