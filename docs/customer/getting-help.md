## 1. Where to ask

- Email: [support contact].
- Website: [website], when it is ready.

[owner legal name] maintains Slate Operations, fixes problems, and answers questions.

## 2. What to send

1. Say what you did, what you expected, and what happened.
2. Add a screenshot if the problem shows on a screen.
3. If the problem is with setup or the server PC, open the Start menu on the server PC. Select **Slate Operations - Save report**. Send the zip file that it saves on your desktop ([plan 10.6](../plans/windows-installer.md#106-save-report)).

The report replaces passwords, keys, email addresses and user names. It is designed to hold no business records (unverified for the logs of third-party parts). Nothing is sent automatically ([plan 10.6](../plans/windows-installer.md#106-save-report)).

## 3. Backups and restore

- To restore the latest backup, use **Restore the latest backup** in Slate Operations settings on the server PC ([administrator guide](administrator-guide.md), section 2.9).
- To restore an older backup, write to [support contact]. This needs a remote session ([plan 8.4](../plans/windows-installer.md#84-restore-in-v1)).

## 4. Remote sessions

[owner legal name] connects to your PC only when you ask for it. You watch the session and can stop it at any time. [owner legal name] uses the session only for your request and does not copy your data.

## 5. What you do

1. Keep the server PC on and connected to the office network.
2. Keep the backup drive connected. Tell [support contact] about a failed-backup warning.
3. Keep the printed or saved recovery key in a safe place. Without it, a backup cannot be read if the PC's disk is lost ([plan 8.3](../plans/windows-installer.md#83-recovery-key)).
